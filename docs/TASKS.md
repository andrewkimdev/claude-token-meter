# 남은 작업 / 미결 `[?]`

끝난 항목은 지우고, 이력은 커밋에 남긴다.

## 실기 미검증
- [?] Mac 슬립/웨이크 후 즉시 재전송된다(구현됨: 30초 넘는 시각 점프를 감지).
- [?] 공유기 재부팅 또는 AP 소실 뒤 재접속한다(백오프 5→60초, 구현됨).
- [?] DHCP로 IP가 바뀌면 mDNS로 다시 알리고, 브리지가 다시 해석한다(구현됨).
- [?] 장시간 운용(수일): 힙 최소값, 재접속 횟수, NVS 쓰기 빈도(5분 스로틀)를 확인한다.

## 알려진 한계 (의도적으로 남김)
- statusLine은 Claude Code가 메시지를 주고받을 때만 갱신된다. claude.ai 웹이나 앱에서 쓴 양은 다음 CC 메시지 때 반영된다.
- 재부팅 직후에는 저장된 `last_seq`와 실제 마지막 seq 사이의 하트비트를 1회 재생할 수 있다. 영향은 낮다.
- WebServer는 헤더를 내부에서 읽으므로, slow-loris 공격이 WDT 재부팅을 유발할 수 있다(LAN 한정).
- USB 경로에는 `old_seq` 재동기화가 없다. 호스트 seq가 epoch 기반이라 Mac 시계가 크게 뒤로 갈 때만 문제가 된다.

## 선택 기능 (아이디어)
- WiFi 경유 OTA(ArduinoOTA를 페어링 키로 보호)
- 모델별 주간 한도: statusLine에 해당 필드가 생기면 추가한다.
